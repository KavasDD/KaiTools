# 小开工具箱 v1.6.47

本版修复 Capture 插件首次安装及目录识别。

- 优先使用用户配置，支持创建缺失的 capAutoLoad；找不到用户目录时检查实际 Capture 安装目录。
- 自动查找失败时，可选择 SPB、SPB_Data 或 capAutoLoad，或通过 XIAOKAI_CAPTURE_AUTOLOAD 指定目录。
- 复制前检查目录与写入权限，记住成功安装位置供插件识别与卸载使用。

安装后重启 Capture，按 Alt+K 打开原理图插件集合。绿色版不会自动安装插件。

本次修正该条 Release 原先损坏的中文标题和说明，v1.6.47 的安装包、源码包与校验文件保持原样。最新功能请下载最新版本。
