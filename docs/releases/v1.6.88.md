# 小开工具箱 v1.6.88

本次同步已完成的 Allegro SKILL 集合及工具箱更新。

- Allegro 按 Alt+K 打开集合：查看 A1–A9、丝印与文字 B1–B2、过孔与走线 C1、检查 D1–D9；点击分类展开，双击工具名运行。
- 一键设置光绘整合自动光绘、层叠颜色与 Film 排序；支持元件即时查找、DRC 浏览、10 组显示配置及过孔框选改网。
- 安装版默认部署保留的 Allegro SKILL，主程序 Allegro 工具页列出功能、说明与安装位置。升级后请重启 Allegro / Capture。
- 修复 Allegro 菜单入口，主工具箱 AI 设置改名为 API KEY，保留统一接口配置与 AI 命令辅助。
- 同步常见丝印反查和两套黑红外观。

## 下载

- `XiaokaiToolbox-setup-v1.6.88.exe`：安装版，默认安装 Capture / Allegro 插件。
- `XiaokaiToolbox-portable-v1.6.88.zip`：绿色版，解压运行主程序；不会自动部署 Cadence 插件。
- `XKGJX-source-v1.6.88.zip`：与本次安装包对应的完整源码和构建脚本。
- `SHA256SUMS.txt`：以上三个文件的 SHA-256 校验值。

运行环境：Windows 10 / 11、.NET Framework 4.7.2 或更高版本；Cadence 需自行安装。Allegro 工具已在 17.4 上验证，其他版本尚未验证。工具说明见仓库 `toolbox/allegro/README.md`。
