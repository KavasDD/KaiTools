# 窗口背景设计预览

打开 `index.html`，可切换六套设计，并比较「纯背景」与「窗口效果」。
`contact-sheet.png` 是六套窗口效果的总览。

| 窗口 | A：电路细线 | B：极简流线 | 配色 |
| --- | --- | --- | --- |
| 小开工具箱 | toolbox-a 深海电路 | toolbox-b 静谧流光 | 深蓝 / 青色、蓝灰 |
| OrCAD 原理图工具 | orcad-a 蓝白图纸 | orcad-b 晴空流线 | 蓝 / 白 |
| Allegro SKILL 工具 | allegro-a 赤焰走线 | allegro-b 曜黑弧光 | 黑 / 红 |

每套包含：

- `名称.svg`：1600 × 1000 的可编辑背景，不含文字、按钮和品牌标识。
- `名称.png`：1600 × 1000 的栅格背景。
- `名称-window.png`：1200 × 750 的窗口效果示意。
- `名称-window.html`：窗口效果的可编辑 HTML。

背景由代码绘制的矢量线条、网格和渐变组成，未调用 AI 生图或 API。`build_previews.py` 可重新生成 SVG 与 HTML，`render.ps1` 使用本机 Edge 导出 PNG。

设计依据：工具箱参考现有左侧分类、右侧工具与插件区域；内部窗口参考现有原理图插件集合与 SKILL 分类列表，实际工具名称来自现有源码。背景把图形主要放在右侧与底部，为文字与列表留出安静区域。窗口图中的控件样式为配套概念，未接入或修改现有程序。

接入注意：WinForms、Tk/ttk 与 Allegro 原生窗体的背景和控件绘制方式不同。SVG 可用于网页或支持矢量的绘制路径；PNG 可用于位图背景。列表、树与按钮需分别设置配套颜色，原生 Allegro 表单是否能承载图片需在接入阶段验证。
