# AI 命令辅助（工具箱 v1.6.70）

在小开工具箱左下角「AI 设置」统一填写 API 地址、Key，获取模型列表后选择并保存。支持 Chat Completions 兼容接口。原有配置自动沿用，Key 使用 Windows 当前用户 DPAPI 加密；星号表示已保存，留空保留，勾选清除才会删除。

安装新版安装包后重启 Capture / Allegro。在图纸或板图中按 Alt+K，点击集合窗口的「AI 命令辅助」。同一窗口输入要求，Ctrl+Enter 或「发送」执行，过程和失败原因显示在底部，回答显示在对话里。等待期间可取消。

当前支持：

- OrCAD：当前页空白处放置 1～32 条带网络名导线、放置红色 Text、按位号选择当前页器件、调出 DRC/BOM/网络定位/立创元件工具。
- Allegro：按位号定位当前板图器件；调出元件列表、DRC、格点、层显示、单位换算、焊盘高亮、库路径、高度文字、光绘设置、过孔网络修改、悬空检查等现有工具。调出工具后具体设置仍在相应工具中操作。

示例：`放置4条带网络名的导线到空白处`、`放置两条网络线，网名 SPI_CLK 和 SPI_MOSI`、`在空白处放置Text：检查电源`、`定位R12`、`打开DRC检查`。

导线是真实的 OrCAD 导线和 Net Alias。自动网名为 XKA_批次前缀_序号；显式网名若在工程中已有同名引脚网络或导线标签，会拒绝放置，防止意外并网。空白判断使用当前页原生图元边界、导线端点和标签范围，放置后核对端点和内容，并跳转到放置区域。放置范围是当前页；尚未限定到原来的可见视口。用户需要的区域没有足够空间时不会覆盖原有图元。

首版不支持任意自然语言修改：新增元件、移动/删除、连接现有引脚、修改已有网络、PCB 自动布局布线等动作仍需逐项实现。模型只能返回允许的动作和数据，不执行模型生成的 Tcl、SKILL 或系统命令。缺少信息和不支持的动作在原对话中说明。

工程上下文会发送至所配置的 AI 服务，内容包括当前页/板图名称和器件位号；该命令助手不上传 DSN/BRD 原文件。OrCAD 执行前核对设计、页面和事务版本，重新计算避让。操作后保持工程未保存状态，由用户正常保存。复查仅验证操作对象、内容和几何，不代表整体电气正确。

开发验证：

- `command-native-tests.tcl`：独立 Dbo 会话、样例副本，放线/标签/Text、重复网名、过期请求、保存重开。
- `command-tests.py`：本机 HTTP 模拟，命令边界、参数、批次与取消；需先运行 `ai-transport-tests.py` 构建测试程序。
- `command-integration-tests.py`：实际 WinForms 对话→本机 HTTP→Tcl 双向管道→样例原生数据库→对话显示结果。
- `command-gui-tests.py`：实际共享设置窗的模型获取、Key 显示/保留和重开；需先运行上述集成测试。

测试不读取真实 Key，不修改用户打开的工程。现有 DRC、传输、界面和工具箱检查同时通过。Allegro 适配器通过 SKILL 解释器加载与模拟数据库上下文校验；实际板图上的对话与工具调用仍需使用者验证。
