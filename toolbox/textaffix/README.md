# 文字前后缀（OrCAD Capture 17.4 内嵌工具）

在原理图中按 **Alt+K → 5. 文字前后缀**。

1. 输入要添加的文字，例如 `NC/`。
2. 选择“添加到现有文字前”或“添加到现有文字后”。
3. 打开窗口后默认连续添加，回到原理图单击属性文字、导线、网络标签、页间连接符、层次端口或电源符号，也可框选。符号本体和符号的名称文字均可点选；未接导线的符号也能处理。
4. 按 **Esc** 停止并关闭工具窗口；在原理图或工具窗口中按 Esc 均可。

例如，`NC/` + “前”会把 `10K` 改为 `NC/10K`；`/NC` + “后”会改为 `10K/NC`。

单击元件显示出来的属性文字时，修改该属性的值。框选或单击元件本体时，默认修改 `Value`，也可在窗口里输入其他已有属性名，例如 `PCB Footprint`。属性和网络可分别开关；没有该属性的元件会跳过。

网络以当前 schematic 为范围，同步修改其各页同一网络的别名、端口、电源和跨页连接名称。同一次框选中的多段同网导线只处理一次；自动命名、没有可见标签的网络会创建别名。此操作修改实际网络名称。层次接口连接到其他 schematic 时，应检查父子接口名称是否仍匹配。

默认勾选“已有相同前缀／后缀时去掉原有前缀／后缀”：已有则去掉一层，没有则添加。例如连续单击 Value 时，`10K → NC/10K → 10K`。取消勾选则每次都添加，允许重复。只识别所选位置：选择“前”时不处理文字末尾的相同内容，反之亦然。

点击“撤销上次处理”可按批次恢复本工具最近 50 次处理。撤销前会核对目标是否仍存在及文字是否仍与处理后相同；若已被其他操作修改，会保留当前内容并提示。关闭设计后清空撤销记录。使用工具窗口内的撤销按钮撤销本工具操作。

窗口内可直接修改文字、前后位置和目标属性；修改设置后继续单击原理图即可。也可先选择对象，再点“处理当前选择”，执行一次处理。工具不自动保存设计，请按平时方式保存 DSN。

随工具箱安装包安装；安装后重启 Capture。临时加载可在 Capture Command Window 执行：

```tcl
source {D:/selfsoftware/autoload/textaffixMenu.tcl}
textaffixMenuRun
```

开发源码为 `core.tcl`、`capture.tcl`、`ui.tcl`；运行 `build.py` 生成单文件 `autoload/textaffixMenu.tcl`。不需要安装 Python 或其他运行库。脚本内包含一个无窗口的 Esc 监听程序，打开工具时释放到 `%LOCALAPPDATA%\XiaokaiToolbox\textaffix` 并启动，只响应 Capture 在前台时的 Esc；关闭工具或退出 Capture 后结束。
