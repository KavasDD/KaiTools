# 常见丝印反查

从小开工具箱的“其他辅助工具 → 常见丝印反查 v1.0”打开。工具与 65 条资料均离线运行，不依赖 Python 或 Cadence。

- 输入丝印、型号、厂商、封装或参数，实时搜索；不区分大小写，兼容全角输入及 `SOT23-5` / `SOT-23-5` 写法。
- 空格分隔多个条件，例如 `SL SOD123`；同时满足所有条件的条目才会显示。
- 类别和封装可组合筛选；选择“仅丝印”并勾选“精确匹配”可查完整丝印。
- 型号别名用 `|` 分隔，同码的多个候选会分别保留；完整丝印匹配优先显示。
- 选中记录查看参数、来源和核对说明，点击“复制条目”复制完整记录。Ctrl+F 聚焦搜索，Esc 重置筛选。

其中 39 条初始资料来自用户整理；新增 26 条范例及原有 K72 条目已核对厂商数据手册中的型号标识和封装。网上补充包括 MMBT3904/3906、MMBT2222A/2907A、MMBT4401/4403、BAV70/99/99W、BSS138/84、DMP2305U、DMG2302UK/2305UX、AP2112 以及 AZ1117C。来源、文档版本、页码和下载文件校验值见 [SOURCES.md](SOURCES.md)，具体记录也包含可复制的官网链接。

用户初始资料未逐项以厂商数据手册验证。GF1 系列对应关系、L435D / C3H 的追溯码性质、MMBD4148W 的封装组合等不确定信息在具体记录中标注。同一丝印可用于不同厂商和不同器件，应结合封装、厂商与电路确认。

## 维护与验证

`markings.tsv` 是 UTF-8 的八列表格：丝印、型号、类别、封装、厂商、参数/用途、备注、来源。修改后重新编译；库作为资源嵌入 EXE，安装版与绿色版无需额外数据文件。分类用“器件大类 / 子类”。封装与批次码疑点应写在备注中，不能作为确定的替代料依据。

```powershell
powershell -NoProfile -File toolbox/markinglookup/build.ps1 -Test
```

测试覆盖全部初始丝印、别名、同码多候选、条件组合、空结果及真实 WinForms 搜索/筛选/缩放布局，并生成 `out/markinglookup-preview.png`。主工程 `build.ps1 -Test` 会一起执行。
